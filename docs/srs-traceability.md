## Status Definitions
- `IMPLEMENTED — LOCAL VERIFIED`: End-to-end frontend and local/mock business logic verified via unit tests, TypeScript type checking, and production build.
- `IMPLEMENTED — REMOTE VERIFICATION PENDING`: Database schema, views, stored procedures (RPCs), and RLS policies created and compiled in migrations, awaiting execution on hosted Supabase/PostgreSQL.
- `PARTIALLY IMPLEMENTED`: Core workflow functional, but secondary enhancements or multi-item UI variations remain in progress.
- `THIRD-PARTY INTEGRATION PENDING`: Code architecture and gateways ready; live credential binding and live third-party testing (Paystack, SMS, WhatsApp, GPS, Weighbridge hardware) pending client provisioning.
- `CLIENT BUSINESS RULE REQUIRED`: Architecture supports configuration, but official business constants or taxation rates must be supplied by AR Multiventures.
- `DEFERRED`: Intentionally scheduled for post-MVP / Phase 10+ release.
- `NOT IMPLEMENTED`: Not present in the current codebase.

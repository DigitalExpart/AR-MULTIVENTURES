# Supabase Backend Placeholder

This directory is structured for the upcoming Supabase backend integration phase:

- `migrations/` — PostgreSQL schema migrations and table definitions
- `functions/` — Supabase Edge Functions (e.g. server-side pricing engine, automated SMS/WhatsApp dispatch alerts)
- `seed/` — Seed data for quarries, material catalog, fleet trucks
- `policies/` — Row Level Security (RLS) policies for customers, hauliers, and operators

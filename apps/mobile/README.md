# AR Multiventures Mobile App

This directory is reserved for the upcoming React Native / Expo cross-platform mobile application.

The mobile app will consume shared packages from this monorepo:
- `@ar-multiventures/types` (Domain models and status enums)
- `@ar-multiventures/validation` (Form validation schemas)
- `@ar-multiventures/business-logic` (Formatters and domain rules)
- `@ar-multiventures/config` (Brand tokens, steps, navigation)
- `@ar-multiventures/api` (Repository interfaces for Supabase backend)
